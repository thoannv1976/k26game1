Game mô phỏng thành phố ảo giúp sinh viên luyện **Nghe – Nói tiếng Anh B1–B2** bằng cách trò chuyện
bằng giọng nói với nhân vật AI tại sân bay, nhà hàng, trường đại học…

Chạy trên Google Cloud (Cloud Run, Vertex AI Gemini, Speech-to-Text, Text-to-Speech) và Firebase
(Hosting, Authentication, Firestore).
